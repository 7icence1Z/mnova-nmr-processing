# 一维氢谱版式与验收

先按 [display-style.md](display-style.md) 设置主谱及每个 Expansion 的显示属性。本文件只负责对象布局与阅读质量；参考成品只提供布局，不提供当前样品的峰位、积分或归属。

## 页面布局

- 主谱覆盖 -1 至 14 ppm、左高右低，保留足够垂直绘图区；不能压成底部矮条再完全依赖放大图。
- 结构式及报告可放左侧，Expansion 可放上方或右上方无信号区；位置随样品调整，不用固定坐标。未知结构使用未归属报告，候选结构明确标记。
- Expansion 与主谱使用同一定标、峰线颜色及积分比例，细边框清楚，不遮挡全谱峰顶、积分或标签。
- 所有谱图、结构及文字保留原生可编辑对象，不以贴入的截图代替。

## 峰高、积分与峰标

- 纵向缩放以最高峰不截顶、弱峰可辨为准。出现对象遮挡时先移动结构、报告或 Expansion，再适度调整上限；不隐藏真实信号或过度压低弱峰。
- 主谱保留可读积分和必要峰标；详细线标优先放在 Expansion，减少拥挤但不删分析对象。
- 绿色积分曲线在峰线以上，最高点靠近峰标下缘且留清晰间隙；按当前页调整起点和显示高度，不让曲线穿过标签或覆盖峰顶。
- 积分段和数字放在基线以下，与 ppm 刻度分开。留出足够高度；主谱与 Expansion 的实测数值及归一化一致。
- 峰标和短引线指向真实峰顶或峰组，避免相互穿越、误指其他信号。溶剂/内标及保留的杂质与样品标识区分；弱峰不能仅因强度低而删除。
- 未分辨芳香区使用数据支持的 m 和区间；放大图帮助判断分辨程度，不制造理论裂分。化学规则见 [manual-analysis.md](manual-analysis.md)。

## 报告字形

英文、数字及化学符号显式用 Times New Roman，通常从 10–12 pt 调整；中文片段用当前环境可用的匹配衬线字体。正文常规字重、左对齐，自然换行，不用两端对齐拉大字距。字体缺失时说明并按用户选择处理，不静默替换。

正确显示 ¹H、δ、溶剂下标及斜体 J，数值与单位用常规字形。文本框容纳完整报告，不裁切或把归属拆成碎片。数据、可靠 J 和氢数/相对积分的报告格式见解析规则。

## 完整页面检查

保存并重新打开后，按常规整页观看大小检查：

1. 主谱、Expansion、结构和报告均在页面内，无裁切或遮挡，真实低场/高场和弱峰可见。
2. 峰标引线、绿色积分、积分数字及 ppm 刻度分层清楚；主谱本身可读，不能仅靠放大图通过验收。
3. 定标、分析对象、积分数值及解析文字一致；有依据的归属在可见报告中出现。
4. 字体、上下标、斜体 J 和字距正常，无替换、乱码或过度换行。
5. [显示规范](display-style.md) 的关闭项在所有谱图生效，原生分析对象仍保留。

用户提供参考成品时按相同显示大小对照；保留当前要求的谱宽，其余显示关系明显退步时调整并重新检查。
