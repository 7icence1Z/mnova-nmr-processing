# 人工选择峰、积分与多重峰

## 判断分辨程度

频率只是背景信息，不是统一阈值。实际信噪比、线宽、重叠和数字分辨率决定能否识别裂分。400 MHz 数据尤其需要放大观察芳香区，但不要假定所有 400 MHz 芳香信号都不可解析，或所有 600 MHz 小峰都应标出。

先逐区辨认真实信号，再明确范围和选择。可读取数字谱点或导出数值辅助判断；计算辅助不应变成全谱自动拾峰、自动积分或自动裂分的替代。

## Manual Peak Picking

- 标记可靠可分辨的峰，涵盖所有可分辨样品峰组；不逐个标注噪声局部极大值。
- 对清晰的 d/t/dd 等，选择支持裂分判断的真实谱线；对未分辨或重叠的芳香包络，用区间和 `m` 描述，不为填满标签而选小凸起。
- 小峰不能仅因强度低就删掉。检查其是否为真实弱信号、杂质、溶剂或卫星峰；不要让主产物峰表混入未经区分的杂峰。
- 溶剂/内标单独标识，不计入样品氢数。需要保留的杂质可以单独说明。
- 主谱标签简洁，局部放大容纳详细线标；不是把所有真实谱线都隐藏。

## Manual Integration

- 人工选取完整峰组两侧合理基线位置，避免截掉峰尾，并检查积分曲线在信号外平直。
- 溶剂或杂质重叠时先评估能否可靠分区；不能简单切出中间一段、遗漏样品信号后仍报告精确氢数。
- 选择结构支持且干净的非交换信号作为归一化锚点，显式设为其实际氢数。其余积分以同一比例核对，不把所有积分独立强制改成理论整数。
- 无法分开的样品信号允许共同积分和联合归属。报告氢数应有结构和实测比例支持，文档保留实测积分。
- OH/COOH/NH 等交换性信号可能宽、弱或缺失；不为了满足分子式总氢数补造峰或强制归一化。看得到时单独评估并说明可靠程度。

## Manual Multiplet Analysis

- 人工定义峰组范围，结合清晰谱线选择 s、d、t、q、dd 等。可以在选定区域调用 Mnova 辅助计算，但人工核验模式和参与谱线，不接受全谱自动结果作为最终答案。
- 未可靠分辨、重叠或呈复杂二级外观的信号可报告 `m` 和化学位移区间；不强行拟合成 d/dd，不虚构 J。
- 只对可信裂分报告 J。由 ppm 间距换算 Hz 时使用本实验频率；400 MHz 与 600 MHz 不可混用。
- 多重峰范围、峰标、积分和结构归属须一致。比较范围时以同一频率、同一定标后的谱图为准。

## 报告格式

`¹H NMR (<实际频率> MHz, <实际溶剂>) δ <位移或区间> (<模式>, J = <可靠值> Hz, <氢数>H, <归属>), ...`

通常按化学位移从高到低列出。`m` 无可靠 J 时省略 J 字段；宽单峰有证据时用 `br s`。位移和 J 的小数精度服从数据质量。避免将所有芳香区一概合并，能可靠分开的峰组仍分别描述。
