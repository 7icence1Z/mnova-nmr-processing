# Mnova 一维氢谱处理

默认用户已安装并激活 MestReNova。使用 Mnova 本身导入、处理和保存可编辑文档；不以外部绘制的谱图或改扩展名的文件代替 `.mnova`。

## 工作边界与默认设置

- 用户只要求准备或规划时，只检查数据、要求与可用接口，不正式处理作业。授权处理后继续完成，不因每个 manual 操作反复请求确认。
- 主谱默认显示 **δ -1 至 14 ppm**，按 NMR 惯例左侧 14、右侧 -1。用户明确改变范围时遵从其要求。
- 仪器频率、核种、溶剂和数据格式从当前采集参数读取。400 MHz 常见，但不是默认填充值；600 MHz 或其他频率同样支持。缺失或冲突且影响解析时再询问。
- 标准预处理为 **自动相位校正 + 自动基线校正**。检查效果，不能仅因命令成功就认为结果正确。确有失败时局部修正并说明原因。
- **峰拾取、积分、多重峰分析均采用 manual 方式**：逐区观察后选择峰、积分边界和多重峰范围。manual 指逐区判断和显式设置，可由代理操作或脚本执行已判断的选择，不意味着必须把每一步交给用户。不得以全谱自动分析结果直接替代。
- 必须保存 `.mnova`；仅在用户要求时导出 PDF。输入和输出路径分开，保留原始数据；默认不覆盖已有示例或作业。
- 本 skill 聚焦一维氢谱。遇到二维或其他核种，先明确额外范围，不套用氢谱规则。

## 执行流程

1. **识别输入和要求。** 找到实验目录及 `fid`、采集参数；Bruker 数据保留 `acqus` 等关联文件。多实验目录先按核种和参数选目标，无法唯一确定时询问。读取用户结构、命名及课程要求；本课程基准见 [references/course-profile.md](references/course-profile.md)。
2. **确认执行接口。** 整个生成和核验流程采用纯脚本：Mnova 原生 QtScript 写入可编辑对象，Python 调用进程并辅助谱点分析与绘图，不依赖 GUI 操作。先运行当前安装的 `MestReNova.exe --help`，确认 `--nogui`、`--wait`、`--sf`，再按 [references/mnova-execution.md](references/mnova-execution.md) 执行、查日志和验收。读取随安装提供的 scripting 文档和官方示例；不要因桌面窗口启动失败就认为脚本不可用。无界面接口不可用时说明具体限制，不以窗口操作替代。
3. **导入与预处理。** 导入原始 FID，确认时域数据转换成谱图。检查数字滤波处理等导入设置，应用自动相位、自动基线，放大检查峰形和无信号区。优先保留合理的 Mnova 导入处理设置，避免无依据地固定线宽或过度平滑。
4. **定标。** 根据实际存在的内标或当前溶剂残余峰定标，核验峰身份。不能一律使用 CDCl3，不能拿水峰、未知杂质或“最强峰”充当内标。需要数值时使用可信的溶剂参考资料并核对条件。记录采用的峰和定标值。
5. **逐区人工解析。** 先查看全谱，再放大各信号区；按 [references/manual-analysis.md](references/manual-analysis.md) 显式选择峰、积分区间及 multiplet。区分样品、溶剂和杂质；以谱图证据控制拆分程度，不以理论结构强行造出未分辨的裂分。
6. **结构与归属。** 使用用户确认的结构或可验证的结构来源，插入正确的结构式。直接在报告每组信号的括号中写化学归属，例如 `2H, Ph–CH=` 或 `6H, Ar–H（间位及对位）`；多重峰对象名称也使用直接归属，不用 a/b/c/d 加单独图例解释。重叠信号允许联合归属；不确定的精细位置不虚构。
7. **排版与文字。** 主谱 -1 至 14 ppm；密集处安排局部放大，优先把详细线标放在放大图。可参考二苄叉丙酮成品的页面关系：结构式和规范解析文字置于页面左侧，主谱占页面主体并保留足够垂直高度，不能压成底部矮条；主谱本身显示可读积分和必要峰组标识。芳香区等密集区域的 Expansion 放在主谱上方或右上方；这是一种版式参考，不是固定坐标。Expansion 应保持与主谱一致的定标、峰线颜色和积分语义。积分值放在基线以下、与 ppm 刻度分开的区域；文字清晰、不互相遮挡；主谱绿色积分曲线紧贴峰标下缘并留清晰间隙。纵轴避免过大，保证最高峰不截顶、弱峰可见；低场或高场峰与结构、报告或放大图重叠时先适当上移相关对象，必要时再略增纵轴上限，并重新核验弱峰。结构、归属和规范解析文字应在同一文档中易于辨认。多重峰报告的英文、数字及化学符号明确使用 Times New Roman，正文常规字形、左对齐，正确呈现 ¹H、溶剂下标及斜体 J；不接受默认字体造成的异常字距或字形。详细峰标优先放在 Expansion，主谱保留足够少而清晰的标签。按整页观看大小检查主谱可读性；有用户参考成品时按相同大小对照，发现明显退步就调整脚本重新渲染。详细版式核验见 [references/example-layout.md](references/example-layout.md)。
8. **保存和核验。** 保存新 `.mnova`，在另一次无界面调用中重新打开，检查谱图范围、积分、多重峰、结构和解析文字的原生对象。使用 `page.toPixmap(dpi).save(...)` 渲染页面 PNG 并检查清晰度、裁切及重叠，无需打开窗口。要求 PDF 时从 Mnova 导出并检查完整页面；没有 PDF 要求时，PNG 仅作为核验材料，无需额外交付 PDF。

## 完成判断

课程检查包括正确预处理、定标、-1 至 14 ppm、局部放大、合理纵轴、人工积分归一化、可靠峰标、多重峰文字、结构及归属。脚本退出成功、文件存在或自动评分都不能单独证明化学解析正确。

交付时给出 `.mnova` 路径、可选 PDF、实际频率和溶剂、定标依据及仍影响结果的不确定项，并记录使用的程序、调用命令、处理脚本和无界面核验结果。区分实际完成的步骤和未验证的接口；不要宣称尚未运行的脚本已可稳定批处理。 最终核验还要确认没有把二苄叉丙酮示例的峰位、CDCl3、400 MHz、积分数值或归属文字带入当前样品。
