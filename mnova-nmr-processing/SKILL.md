# Mnova 一维氢谱处理

默认用户已安装并激活 MestReNova。使用 Mnova 原生对象处理和保存可编辑文档，保留原始数据；准备或只读请求不正式处理。其他核种或二维谱需先明确额外范围。

## 默认规则

- 主谱 δ -1 至 14 ppm，左高右低；频率、核种、溶剂从当前采集参数读取。
- 自动相位与自动基线校正后检查效果；峰拾取、积分和多重峰分析逐区人工判断，可用脚本写入已经确认的选择，不接受全谱自动结果直接代替。
- 主谱及全部 Expansion 白色无网格，隐藏多重峰标记、其积分叠加层和纵坐标；保留蓝色峰拾取、普通绿色积分及轴下数值，不删除分析对象。应用 [显示规范](references/display-style.md)，允许原生脚本或等效 GUI 设置。
- 优先接受确定结构，默认解谱后验证；用户可明确跳过结构验证。结构缺失不自动授权猜测；只有用户要求且有合理线索时才进入候选检索。完整分支和所有烯烃的归属要求见 [结构策略](references/structure-policy.md)。
- 保存新 `.mnova`，不默认覆盖已有文件；PDF 仅按用户要求导出。用户指定的课程、命名及显示要求优先。

## 工作流程

1. **识别输入。** 找到完整实验目录，Bruker 保留 `fid`、`acqus` 等关联文件；多实验按核种和参数选目标，不能唯一确定时询问。读取结构、已有线索及输出要求。
2. **确认执行方式。** 使用 Python 标准库启动器 `scripts/mnova_runner.py`，按 [跨平台说明](references/cross-platform.md) 检查当前安装。已知启动崩溃时只做静态检查或准备 GUI 脚本，不重复启动失败模式。原生 API 和实现陷阱见 [执行参考](references/mnova-execution.md)。
3. **预处理与定标。** 导入 FID，检查傅里叶转换、数字滤波、相位和基线。使用实际存在且身份可靠的内标或当前溶剂残余峰定标，记录依据与数值；不以未知杂质、水峰或最强峰直接代替内标。
4. **人工解析。** 查看全谱并逐区放大，按 [解析规则](references/manual-analysis.md) 选择峰、积分边界、归一化锚点和 multiplet，区分样品、溶剂及杂质。不用理论结构强行补出未分辨裂分、氢数或 J。
5. **结构与归属。** 按结构策略验证或保留未归属状态。所有可确定的烯氢环境及几何关系须分别写入原生峰组和可见报告；m 不替代已确定的归属，证据不足的部分单独说明。用户要求猜测且提供线索时，才按 [候选检索](references/candidate-search.md) 调用搜索脚本。
6. **排版。** 按 [版式指南](references/layout-guide.md) 安排主谱、Expansion、结构及规范解析文字；无确定结构时使用未归属报告，候选结构明确标记。显示层按显示规范设置，不能依赖全局默认偏好。
7. **保存并独立核验。** 重新打开 `.mnova`，检查原生分析对象、报告、显示属性及完整页面。正常无界面路径可另次调用；失败模式不用于再次验收，改在正常 GUI 会话检查。PDF 要求存在时导出并检查页面；否则 PNG 仅用于核验。

## 验收与交付

共同验收：预处理、定标、范围、局部放大、人工分析、显示设置、清晰排版及可编辑保存正确，当前数据与报告一致。文件存在、进程成功或已准备脚本不单独证明完成。

- **已知结构：** 完成证据支持的结构与氢归属，报告结构验证结论；用户跳过时明确标为未验证。
- **未知结构：** 可交付未归属谱图、相对积分及可靠片段判断；推测时列候选、支持与矛盾、数据来源和谱性质。未确定结构不是谱图处理失败，不冒充完成唯一结构鉴定。

交付 `.mnova`、按需 PDF、实际频率/溶剂、定标依据与重要不确定项；保留本次脚本、日志及核验材料，简要说明实际执行方式和验证结果。
